隐私政策

成语诗词大搜查 · Android无广告版隐私政策
更新日期：2026年11月1日

本Android版由上海龙城幻景软件有限公司提供。

1. 本地数据

游戏将关卡进度、金币、收藏、成就、设置和随机生成的本地玩家标识存储在本设备的应用数据中。本版本没有账号注册、登录或云存档，不将这些数据上传给我们。

2. 无广告和统计服务

本Android版不集成广告SDK、第三方行为分析SDK或应用内购买服务。游戏中的行为计数用于本地进度和功能逻辑，不向微信或其他统计平台发送。

3. 主动分享与剪贴板

仅当你点击分享时，游戏才调用Android分享面板，将你选择分享的游戏文字交给所选应用。所选应用按其自身隐私政策处理这些内容。仅当你点击复制玩家ID时，游戏才向系统剪贴板写入该ID；游戏不读取剪贴板。

4. 数据权限

本版本不请求通讯录、位置、相机、麦克风、电话或广告标识符权限。

5. 删除数据

你可以在Android系统“设置—应用—成语诗词大搜查—存储”中清除本地数据，或卸载应用。清除数据后进度无法恢复。本Android版关闭Android云备份。

6. 联系

关于本Android版的数据问题，请联系：chnmlong@hotmail.com。

本政策仅适用于本Android无广告版。加入联网、广告或账号功能前，将相应更新政策和声明。

1. Local data

Level progress, coins, collections, achievements, settings and a randomly generated local player identifier are stored in this app's data on your device. This build has no account registration, login or cloud saves. We do not receive these records.

2. No advertising or analytics services

This Android version has no advertising SDK, third-party behavioral analytics SDK or in-app purchase service. Gameplay counters support local progress and game logic and are not sent to WeChat or other analytics services.

3. Sharing and clipboard

Only when you choose Share does the game open the Android share sheet and pass the game text you chose to the selected app. That app handles the content under its own privacy policy. Only when you choose Copy player ID does the game write that ID to the system clipboard. The game does not read the clipboard.

4. Permissions

This build does not request contacts, location, camera, microphone, phone or advertising identifier permissions.

5. Deleting data

Use Android Settings > Apps > ChineseLink > Storage > Clear data, or uninstall the app, to delete local game data. Deleted progress cannot be recovered. Android cloud backup is disabled for this Android version.

6. Contact

For questions about data in this Android version, contact chnmlong@hotmail.com.

This policy applies only to this ad-free Android version. The policy and disclosures will be updated before online, advertising or account features are added.
